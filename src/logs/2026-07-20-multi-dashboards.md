# 2026-07-20 — Multiple dashboards + view/edit modes

**Автор:** PM / BE-CTRL / FE  
**Фаза:** feature loop

## Сделано
- Несколько дашбордов на устройство (UNIQUE user+device+name)
- API: list/create/get/update/delete
- UI список `/devices/:id/dashboards`, карточка `/devices/:id/dashboards/:dashboardId`
- Режимы **Просмотр** / **Редактирование**
  - Просмотр: без левой/правой панелей, холст на всю ширину, без DnD
  - Редактирование: палитра + свойства + save (как раньше)
- Миграция constraint на живой БД
- control + web пересобраны

## План дальше

## Как проверить
1. Устройство → **Дашборды** → создать 2 шт.  
2. Открыть → по умолчанию **Просмотр** (без боковых панелей)  
3. **Редактирование** → панели появляются, сохранить  
4. Снова **Просмотр** — панели скрыты, контент шире
