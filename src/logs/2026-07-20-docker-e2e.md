### Фиксы в этой сессии
1. **Симулятор vs race Compose** — wait на `/health` control+ingest перед register; `restart: unless-stopped`.  
2. **Email `@signaldeck.local`** — Pydantic EmailStr отклоняет `.local` (422). Заменено на `admin@example.com`.  
3. **Грязная БД после ручных тестов** — `down -v` и чистый подъём (иначе email/user mismatch → 401).  
4. Dockerfile/README симулятора: `SIGNALDECK_*` вместо OS `USERNAME` / `.local` email.

## Подводные камни

| Камень | Почему важно | Как жить дальше |
|--------|--------------|-----------------|
| **EmailStr ≠ `.local`** | Register 422, симулятор в restart loop | Demo email только публичные домены (`example.com`) |
| **depends_on ≠ ready** | Simulator стучится в control до uvicorn listen | Ждать `/health` в коде клиента + restart policy |
| **Volume после кривых тестов** | User с одним email и другим username → login 401 | `compose down -v` на чистый стенд; не мешать ручные register с demo |
| **PowerShell + curl JSON** | Ломает кавычки в `-d "{...}"` | Python `urllib` / файл JSON / `ConvertTo-Json` |
| **Первый `up --build`** | Долго тянет golang/python/node образы | Нормально 2–5 мин; последующие — cache |
| **Профиль `demo`** | Без него нет симулятора | Всегда `--profile demo` для happy path |
| **Пересоздание control/ingest при rebuild sim** | Краткий downtime | Сначала дождаться healthy, потом смотреть логи sim |
