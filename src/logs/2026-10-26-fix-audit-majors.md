## Сделано

- До правок прогнаны тесты HTTP-контракта: верный `X-API-Key` сохраняет announce/telemetry, пустой и чужой ключ — 401, битый JSON — 400. Симулятор по-прежнему кладёт ключ в заголовок, не в JSON.
- MQTT: в JSON publish есть `api_key`. Брокер без анонимного входа, пользователи `ingest` и `devices`, ACL не даёт `devices` читать telemetry. Смена ключа устройства не подменяет логин брокера.
- Telemetry пишется только если имя и тип совпали со схемой. `received_at` и `last_seen_at` — время сервера.
- History, latest и WebSocket требуют JWT владельца. UI добавляет `access_token` в URL сокета. History по-прежнему идёт с Bearer.
- Контракт: [../docs/device-contract-v0.md](../docs/device-contract-v0.md).
