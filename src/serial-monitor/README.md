# USB-монитор датчиков

Локальный сервис читает последовательный порт платы и показывает показания и последние 100 текстовых сообщений в браузере. Интернет и запущенный SignalDeck для просмотра не нужны. Сервис слушает только `127.0.0.1`; данные хранятся только в памяти процесса.

## Запуск

Из корня репозитория в PowerShell:

```powershell
python -m venv .tools/usb-monitor-venv
.\.tools\usb-monitor-venv\Scripts\python.exe -m pip install -r src/serial-monitor/requirements.txt
.\.tools\usb-monitor-venv\Scripts\python.exe src/serial-monitor/app.py
```

Откройте `http://127.0.0.1:8765`, выберите COM-порт платы, скорость `115200` и нажмите «Подключить». Для другого HTTP-порта запустите с `--port 8766`. Для остановки нажмите «Завершить USB-монитор» на странице или `Ctrl+C` в терминале.

Порт может быть занят Arduino IDE, PlatformIO или другим монитором. Отключите USB-монитор перед загрузкой прошивки или изменением настроек платы. Сервис не пишет в последовательный порт и не посылает команд управления; управляющие линии DTR/RTS задаются выключенными до открытия порта. Особенности USB-драйвера или платы всё же могут вызвать сброс при открытии или закрытии порта.

Прошивка `firmware/esp32-dht22` раз в две секунды выводит структурированную строку даже без Wi-Fi и настроек SignalDeck. Таймауты HTTP не блокируют отдельную задачу опроса датчиков. Если DHT22 не отвечает, значения выводятся как «Нет данных», а страница показывает ошибку. Если строка не обновлялась более шести секунд, отображается отметка об устаревших данных. Состояние реле обозначает уровень GPIO, а не подтверждение физических контактов.

## Подключение другого скетча

Любой Arduino-совместимый скетч может отправлять обычные строки в последовательный порт: они появятся в разделе «Сообщения порта». Для карточек значений раз в нужный интервал выводите строку UTF-8 с префиксом `SD_SAMPLE ` и JSON-объектом в одной строке, завершённой `\n`:

```text
SD_SAMPLE {"kind":"sample","version":1,"device_id":3,"uptime_ms":10000,"sensors":{"temperature":22.5,"humidity":50,"motion":false},"actuators":{"relay_1":false},"errors":{"dht22":false}}
```

`sensors`, `actuators` и `errors` — объекты с простыми значениями; отсутствующее показание передавайте как `null`. Имена дополнительных метрик выводятся как есть. Строки без этого формата остаются доступными как обычный текст порта. Не выводите пароли или ключи в последовательный порт.
