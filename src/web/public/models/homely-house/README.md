# Tiny Treats — Homely House set

Stylized low-poly house and exterior props used by the Overview digital twin.

## Source

- **Primary:** [Tiny Treats - Homely House set on itch.io](https://tinytreats.itch.io/homely-house) by Isa Lousberg / Tiny Treats
- **Mirror used for download:** [OpenGameArt — Tiny Treats Homely House](https://opengameart.org/content/tiny-treats-homely-house-set) (`tiny_treats_homely_house_1.0.zip`)
- Also listed on [Poly Pizza](https://poly.pizza/bundle/Homely-House-Set-zECUN0FUzz)
