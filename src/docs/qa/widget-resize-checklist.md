# QA checklist — resize виджетов (edit mode)

## Окружение
- [ ] `docker compose --profile demo up -d` из `deploy/`
- [ ] UI http://localhost:3000 · login `admin` / `admin123` · demo-дашборд с ≥2 виджетами
- [ ] Ширина окна ≥768px (resize/drag только на desktop/tablet)

## SE resize (правый нижний угол)
- [ ] Режим «Редактирование» → выбрать виджет → виден handle в правом нижнем углу
- [ ] Курсор над handle — `se-resize` (или diagonal resize)
- [ ] Тянуть handle вправо-вниз — виджет растёт, snap к сетке 12 col
- [ ] Тянуть handle влево-вверх — виджет уменьшается
- [ ] Во время resize контент виджета не «ломается» (chart/gauge перерисовываются)

## Минимальный размер
- [ ] Нельзя ужать виджет меньше **2×2** ячеек (w≥2, h≥2)
- [ ] При попытке меньше — размер «упирается» в минимум, без ошибок в консоли
- [ ] Максимум: ширина ≤12 col, высота ≤12 rows

## Drag не ломается
- [ ] После resize виджет перетаскивается за handle «⋮⋮» в header
- [ ] Resize handle не запускает drag; drag handle не запускает resize
- [ ] Перетаскивание snap к сетке; соседние виджеты не смещаются автоматически
- [ ] Клик по canvas вне виджета снимает выделение

## Режим «Просмотр» — без handles
- [ ] Переключить «Просмотр» → resize handles **не видны**
- [ ] Виджеты не выделяются, drag недоступен
- [ ] Клик по toggle/switch в view mode работает как раньше

## Сохранение
- [ ] Изменить размер → «Сохранить» → toast «Дашборд сохранён»
- [ ] Reload страницы — w/h совпадают с сохранёнными
- [ ] «Сбросить» до save откатывает размер к последнему сохранённому layout

## Тёмная тема
- [ ] Настройки → dark → handle и рамка выбранного виджета читаемы (контраст ок)
- [ ] Resize в dark без артеfactов; после save/reload размер сохраняется
- [ ] Переключение light ↔ dark не сбрасывает несохранённый resize
