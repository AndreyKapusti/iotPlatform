## Аккаунт и профиль

| Идея | Зачем | Заметки |
|------|--------|---------|
| **Подтверждение email** | Доверие к контакту, восстановление доступа | Токен в письме / magic link; статус `email_verified_at`; до verify — мягкое предупреждение в UI |
| Смена `username` | Гибкость логина | Нужна ротация JWT / re-login; уникальность |
| Смена пароля из профиля | Безопасность | Текущий + новый; rate limit |
| Загрузка аватара | Узнаваемость | Object storage или локальный volume; сейчас — инициалы |
| 2FA (TOTP) | Усиление доступа | Не для MVP / вузовского демо в первую очередь |
| Удаление аккаунта / GDPR export | Compliance | Cascade устройств уже есть; нужен UX подтверждения |
